# tic-tac
tic-tac-toe game
Tic Tac Toe 🎮

A simple two-player Tic Tac Toe game built with HTML, CSS, and JavaScript.

This project was created as part of my JavaScript practice, with a focus on using factory functions, objects, game logic, and DOM manipulation.

🎮 Features
Two-player gameplay
Custom player names
Clickable gameboard
X and O markers
Win detection
Tie detection
Prevents players from choosing an occupied square
Restart game button
Displays the winner or a tie
🛠️ Built With
HTML
CSS
JavaScript
🧠 What I Practiced
Factory functions
Objects and object methods
Managing game state
Arrays
DOM manipulation
Event listeners
Conditional logic
Winning-condition detection
🚀 How to Play
Enter a name for each player.
Click Play.
Players take turns clicking an empty square.
The first player to get three in a row wins.
If all squares are filled without a winner, the game ends in a tie.
Click Play again to restart the game.
